# Trace Helper

Правила и законы Trace RP поверх игры. Автор: Филосов (@f1losovsky).

- **Alt+Q** — открыть или спрятать строку поиска (работает в игре в режиме «Оконный без рамки»)
- поиск по правилам и законам, понимает разговорные слова и неправильную раскладку
- голосовой ввод (Ctrl+Пробел) и ответы ИИ по найденным статьям (Ctrl+Enter)
- кнопка промокода: в настройках можно поставить свой код
- автообновление, режим стримера (окна не видно в OBS и Discord)

## Скачать

Установщик лежит в [Releases](../../releases/latest): `TraceHelper_<версия>_x64-setup.exe`.

## Сборка

Нужны Node.js 22+ и Rust (stable), Windows.

```bash
npm ci
npx tauri dev      # запуск для разработки
npx tauri build    # установщик в src-tauri/target/release/bundle/nsis
```

Без ключа подписи локальная сборка соберёт установщик, но не файл `.sig` для автообновления.

## Как выходят версии

Релизы собирает только GitHub Actions (`.github/workflows/release.yml`):
поднимается версия в `src-tauri/tauri.conf.json`, пушится тег `vX.Y.Z` (`bash release.sh "что нового"`),
Actions собирает установщик, подписывает его ключом из секретов репозитория и выкладывает в Releases вместе с `latest.json`.

## Что программа отправляет в сеть

- GitHub Releases — проверка обновлений и загрузка общей базы правил (`base`).
- `voice-production-39e0.up.railway.app` — только когда ты сам пользуешься голосом, ИИ или отзывом:
  запись голоса для распознавания, текст вопроса с найденными статьями, текст отзыва.
- forum.trace-rp.com — только если ты сам открываешь окно форума, чтобы скачать законы.

Больше ничего не собирается и не отправляется.
